PROJECT IDENTITY (FIXED STACK)
------------------------------
App: ExamBase AI | Platform: Android | Language: Kotlin | UI: Jetpack Compose
Architecture: Clean Architecture + MVVM, Coroutines + Flow, Hilt, Navigation Compose
Local: Room, DataStore, WorkManager, Paging 3, Coil
Network client: choose Retrofit or Ktor Client (compare, then decide in Step 2)
Backend: Kotlin + Ktor, modular monolith, PostgreSQL, Redis, S3-compatible storage, Cloudflare/equivalent CDN+WAF
Deploy: Docker first; Kubernetes only when justified
Admin: separate responsive web app
AI: provider-neutral, server-side only
Localization: English + Bangla

PRODUCT RULES (APPLY IN EVERY STEP)
-----------------------------------
1. Hierarchy exactly: Subject -> Category -> Subcategory -> Lesson -> Questions / Quiz / Flashcards / Notes.
2. Every Quiz Set and Flashcard Set is a separate, identifiable entity (title, description, subject, category, lesson, created date, status, progress, actions) in both UI and database. Never merge them into one list.
3. User-created content stays separate from official/admin-published content.
4. Do not send correct answers to the client before submission when that would compromise integrity.
5. Scoring, payment verification, permissions and contest ranking are validated on the server only.
6. No DB passwords, service credentials or AI keys in the APK.
7. Every major screen has loading, empty, error, offline and retry states, plus accessibility support.
8. Roles: Guest (optional), Registered, Premium (configurable), Moderator, Content Editor, Admin, Super Admin. Authorization is server-enforced (RBAC + resource-level); hiding admin UI is not security.
9. Private notes are private by default; note content goes to AI only after explicit user action and consent.
10. Never log passwords, tokens, private note content or AI secrets.
